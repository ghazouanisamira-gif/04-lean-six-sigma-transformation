# Lean Six Sigma Transformation

## Case Study — Recruitment Process Improvement

A Lean Six Sigma case study focused on improving a recruitment process and reducing early employee attrition through structured problem solving and data analysis.

## Methodology

**Define → Measure → Analyze → Improve → Control**

## Define

### Business Problem

Early employee attrition was identified as an operational challenge affecting recruitment efficiency, workforce stability and performance.

### Project Objective

Improve the recruitment process and reduce early attrition through a structured, data-driven improvement approach.

## Measure

The analysis included:

- Recruitment process mapping
- Baseline performance
- Attrition analysis
- Candidate journey analysis
- Process performance indicators

## Analyze

Tools used or considered within the project included:

- Value Stream Mapping (VSM)
- Pareto Analysis
- Cause & Effect Analysis
- Chi-Square Analysis
- Logistic Regression
- Root Cause Analysis

## Improve

Improvement opportunities focused on:

- Recruitment process redesign
- Candidate screening
- Selection criteria
- Onboarding alignment
- Early-stage monitoring

## Control

The control approach includes:

- KPI monitoring
- Standardized processes
- Management dashboards
- Periodic reviews
- Corrective actions

This repository presents the methodology and selected project elements without exposing confidential company information or personally identifiable data.
