# Process Analysis

## Current-State Analysis

The recruitment process was analyzed as an end-to-end flow:

**Sourcing → Screening → Interview → Selection → Onboarding → Early Retention**

## Analysis Focus

The analysis examined:

- Process steps
- Handoffs
- Waiting time
- Candidate flow
- Selection criteria
- Communication
- Data availability
- Recruitment performance
- Early-stage employee outcomes

## Lean Perspective

The analysis sought to identify:

- Waiting
- Rework
- Unnecessary handoffs
- Process variation
- Lack of standardization
- Information gaps

## Improvement Logic

**Map → Measure → Identify Waste → Analyze Causes → Redesign → Control**
