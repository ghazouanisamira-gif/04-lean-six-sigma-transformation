# Root Cause Analysis

## Objective

Identify and validate the factors contributing to early employee attrition.

## Tools

### Pareto Analysis

Used to prioritize the most significant contributing factors.

### Cause & Effect Analysis

Used to structure potential causes across categories such as:

- People
- Process
- Tools
- Management
- Environment

### 5 Whys

Used where appropriate to move from symptoms to underlying process causes.

### Data Analysis

Potential relationships were investigated using available recruitment and employee data.

## Validation Principle

A potential cause was not treated as a root cause solely because it appeared plausible.

The project applied an evidence-based approach:

**Hypothesis → Data → Analysis → Validation → Improvement**
