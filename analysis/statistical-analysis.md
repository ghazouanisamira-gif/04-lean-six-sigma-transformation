# Statistical Analysis

## Objective

Use data to strengthen root-cause validation and support evidence-based decisions within the DMAIC project.

## Analytical Techniques

### Chi-Square Analysis

Used where appropriate to examine associations between categorical variables and early employee attrition.

The purpose was to test whether observed differences warranted further investigation rather than assuming that a relationship existed.

### Logistic Regression

Used to explore how relevant recruitment / employee variables related to the probability of an early-attrition outcome.

This supported identification of variables requiring managerial attention and helped complement qualitative process analysis.

## Analytical Principle

Statistical analysis was integrated into the operational context.

**Statistical association ≠ automatic causation.**

Findings were interpreted alongside process evidence, stakeholder knowledge and other DMAIC analyses.

## Analytical Flow

**Define Y → Identify X Variables → Validate Data → Analyze Relationships → Interpret → Prioritize → Act**

## Data Governance

For a professional performance study:

- Define the observation period.
- Document inclusion and exclusion rules.
- Validate variable definitions.
- Check data completeness and consistency.
- Separate correlation / association from causal claims.
- Protect employee and candidate confidentiality.
- Keep the analysis reproducible where data can be shared.

## Public Portfolio Boundary

Raw candidate-level data, individual employee records, confidential model outputs and internal statistical tables are intentionally not published.

The public repository demonstrates the **analytical approach and decision logic**, not sensitive source data.
