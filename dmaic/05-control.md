# DMAIC — Control

## Objective

Sustain the improvement and prevent the process from returning to its previous state.

## Control Plan

| Control | KPI | Frequency | Owner | Trigger | Response |
|---|---|---|---|---|---|
| Performance review | | | | | |
| Process audit | | | | | |
| Dashboard monitoring | | | | | |
| Corrective action review | | | | | |

## Sustainability Mechanisms

- Standardized procedures
- KPI dashboards
- Management reviews
- Clear process ownership
- Escalation rules
- Periodic audits
- Corrective action tracking
- Lessons learned

## Effectiveness Check

Compare post-improvement performance with the baseline and verify that the change produces a sustained effect.

## Output

A control framework that transfers ownership to the operational team and embeds continuous monitoring into normal management routines.
