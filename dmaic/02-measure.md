# DMAIC — Measure

## Objective

Establish a reliable baseline and understand the current performance of the process.

## Activities

- Map the current process
- Define performance indicators
- Establish the measurement period
- Validate available data
- Identify data gaps
- Establish baseline performance

## Example Measures

| Measure | Definition | Source | Frequency |
|---|---|---|---|
| Early Attrition | Employees leaving during the defined early-stage period | HR data | Monthly |
| Recruitment Cycle Time | Time from recruitment request to selected candidate | Recruitment data | Monthly |
| Conversion Rate | Candidates progressing between defined recruitment stages | Recruitment data | Weekly / Monthly |
| Onboarding Completion | Completion of required onboarding activities | HR / Training data | Monthly |

## Output

A validated baseline that allows the project team to quantify the performance gap and assess improvement later.
